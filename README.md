# 2023-24-Year2-Mock-Database
This group project was done in year 2, where Me and a group implemented a mock database and a PTUI movie themed app.
The data for the database was given to use by the professor which has not been provided, and therefore makes it not possible to be ran.
Version control was used in my personal school repo, this serves as file holder to be displayed as evidence of existance.
## Logic
Modeled relational schema and built EER diagrams. 
Developed SQL queries for complex data retrieval and reporting. 
Simulated user interaction via Java CLI and maintained GitHub version control.
